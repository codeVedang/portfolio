# Vedang Kumar Tripathi Portfolio

A responsive personal portfolio website built from Vedang Kumar Tripathi's resume.

## Sections

- Hero with resume-based visual treatment
- Experience timeline
- Featured projects with live demo and GitHub links
- Technical skills
- Education and certifications
- Embedded resume preview and downloadable PDF
- Contact links

## Run Locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 5174
```

Then visit `http://localhost:5174`.
